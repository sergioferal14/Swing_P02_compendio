# Swing_P02_compendio

## Descripción del proyecto
En este proyecto se simula una aplicacion grafica en la que se gestionan las altas y bajas de las reservas de un hotel turistico.

## Contenido de la publicación
El contenido del repositorio es el siguiente:

Un directorio llamado Desarrollo en el que se incluye el directorio del proyecto de la
práctica.
Un directorio llamado Ejecutable que contiene el ejecutable de la aplicación.
Un directorio llamado Documentación técnica donde se incluye el javadoc de la aplicación.
Un directorio llamado Documentos donde se encuentra el documento sobre usabilidad.

## Desarrollo del proyecto

El desarrollo del proyecto consistió en la implementación de una interfaz gráfica de usuario (GUI) utilizando Java y la biblioteca Swing. Se diseñó una ventana modal para la gestión de reservas de hotel, estructurando los componentes en paneles organizados por secciones (datos del cliente, datos de la habitación, imágenes y control de acciones). Además, se integraron funcionalidades para validar datos, calcular importes, gestionar dinámicamente los extras y visualizar información mediante pestañas.

## Despliegue
### Cómo ejecutar la aplicación desde el ejecutable

#### Windows
Abrir la carpeta Ejecutable y hacer doble click en el archivo que contiene.

#### Línea de comandos
Posicionandonos en la siguiente ruta desde el terminal:
Swing_P02_compendio\Desarrollo\swing_c_p02_FernandezAlvarezSergio

Introducir el siguiente comando para compilar el programa:
javac -d out -sourcepath src src/swing_c_p02_FernandezAlvarezSergio/*.java

Y ahora lo ejecutamos con el siguiente comando:
java -cp out swing_c_p02_FernandezAlvarezSergio.VentanaPrincipal
